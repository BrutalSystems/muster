# Generic patterns scripts/check-public.sh blocks in anything bound for the
# public repo: extended regexes, matched case-insensitively, one per line.
# Lines starting with # and blank lines are ignored.
#
# Only generic shapes belong here. Names specific to one maintainer's setup go
# in a private terms file outside the repo (see scripts/check-public.sh).
